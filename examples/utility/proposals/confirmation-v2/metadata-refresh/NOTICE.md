# PVDAQ metadata attribution

PVDAQ site 2107 system metadata, published through the Open Energy Data Initiative.
Dataset DOI: [10.25984/1846021](https://doi.org/10.25984/1846021).
Source: [site metadata](https://oedi-data-lake.s3.amazonaws.com/pvdaq/2023-solar-data-prize/2107_OEDI/metadata/2107_system_metadata.json).

The preserved [dataset-specific OEDI catalog record](../../confirmation-v1/oedi-catalog-license.json)
declares [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Those source
terms remain distinct from the package code license. The metadata bytes are
unchanged. Retrieval details and SHA-256 are in `request.json` and `result.json`.
The live submission page returned HTTP 429 in the browser tool during this pass;
no replacement rights statement was inferred. No observation file was acquired.
