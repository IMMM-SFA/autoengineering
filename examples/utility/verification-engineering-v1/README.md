# Supervised engineering verification

This increment qualifies trusted supplied scenario execution on local macOS.
It does not establish an engineering campaign, independent confirmation or utility.

- default-output.txt and default.xml retain all utility tests plus optimization recovery/run-spec tests.
- interoperability-output.txt and interoperability.xml retain engineering process, domain and study checks with OpenMDAO available.
- documentation.xml retains documentation contracts.
- rehearsal.json checks the final retained circuit summary and compares 173 captured runtime/example/lock files with current bytes.
- summary.json records commands, counts and limits.

The full rehearsal journals, jobs, process identities, stops, source inventory and
solver diagnostics remain under ../development/engineering-supervised-v2.
The earlier -v1 directory preserves an earlier development snapshot. Do not
rewrite either directory or relaunch its completed processes as a new study.

The prior full default/Bayes suites and installed wheel predate this increment.
They were not rerun here. No frozen BO benchmark, provider, private confirmation,
remote execution, Linux runtime or second host was used.
