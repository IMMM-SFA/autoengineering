trials on the previously exposed 2007 wind point. Five reservations have five
successful physical observations with verified stop receipts and no pending work.

batch allowed five starts within 600 seconds. No guest, provider, fitting, new
source acquisition or reserved-year data was used. The source and runtime pins
were checked again after execution.

accounted standalone result. The best Sobol trial returned 30.068129320901953 GWh.
