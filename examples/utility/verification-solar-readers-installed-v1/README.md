# Installed solar input reader evidence

The corrected wheel contains 228 Python files: 224 core sources and four utility
example sources. Every Python member matches the 240 copied input pins. Installation
used `pip --isolated --no-index --no-deps --no-compile --no-cache-dir --target`.
It used existing native macOS Python dependencies. This is not Linux, a fresh
environment, a release wheel or the frozen 315-source inference wheel.

The isolated checker loads the target installation and refuses editable source
fallback, model imports, new processes, network, clocks and NumPy archive loading.
After initialization it permits only the relocated authored bundle reads. Its
public phase denies reserved files. Its trusted reserved phase verifies the full
development forcing prefix and confirmation mask. No real observations are here.
Native callers remain trusted; this Python audit hook is not an OS privacy boundary.

The first build used the wrong working directory. Its log and exclusion record
remain here, and its wheel was never installed. The corrected build used only
the staged inputs. The original checker emitted its complete result, but its exit
status was lost across context compaction. Process absence was checked before one
read-only repeat captured exit zero. Both logs remain separate. Neither run starts
a model, trainer or scorer.

`summary.json` records the 85-test regression, packaging scope and admission limits.
`source-snapshot` preserves the exact reader, preparer and unit-test bytes.
`evidence-pins.json` hashes all archive files except itself. Nothing here qualifies
source timing, hardware, exposure, scientific adapters or private execution.

The executed checker is preserved as `installed-reader.py.txt`. The text suffix
keeps an exact execution snapshot out of normal Python lint collection.
