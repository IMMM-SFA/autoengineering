# Dispatch-bound public guest archive

The v2 archive binds original dispatch completion and journal commitments to the
existing job, claim, environment, lifecycle projections, capture and permitted
outputs. The producer checks the original owner, both writers, immutable scopes
and an explicitly pinned publisher implementation before publication. The grant
pointer is create-only and written last. Interrupted publication can finish from
saved evidence without another model, attach or START request. A published archive
with missing or corrupt bytes fails verification rather than being regenerated.

Public metadata keeps the original completion and journal chain. Private dispatch
plans, paths, driver capsules and raw OCI observations are not copied. Original
observation references in the projection are opaque commitments to private
producer records. The public reader verifies their relationships to exported
lifecycle projections and permitted bytes. It does not attest daemon/OS behavior.
The publisher pin is an explicit reader argument, separate from runtime/source pins.
V1 guest archives and the legacy local archive reader retain their contracts.

Cancellation after stop observation cannot promote an existing capture into
scoring outputs. Scientific/model/infrastructure worker failures remain distinct
from complete transport. Lost START responses and truncated output remain failures;
original deadline expiry remains timeout. Missing original start or terminal proof
cannot become a started-execution archive. Unknown original timing remains unknown.
Default confirmation execution/recovery and local archive paths do not admit this
candidate. No registration, scorer allowlist or private runtime was activated.

The first export run failed on a watchdog artifact scope error: the absence record
was read relative to the owner instead of the original watchdog subtree. The
corrected focused check passed 9 cases in 23.92 seconds. The job metadata bound on
published-pointer recovery was also aligned with the existing 4 MiB reader bound.
The related archive/local inference/composite regression passed 93 cases in 186.09
seconds. This included 25 guest archive cases. The expanded final archive check
passed 31 cases in 141.94 seconds, including six publication fault points, eight
public-proof tamper cases, worker failures, lost response, truncation, deadline and
closed service recovery. Source snapshots and pins distinguish the final scope.
An invalid test-target command ran no tests and contributes no passing evidence.

All daemon state and guest output are authored. Native Unix peers exercise the
actual existing watchdog/attach path. No actual container, image or guest model
runs. The metadata fixture includes ordinary authored development execution.

The minimal retained public archive has 17 files, including metadata, permitted
outputs and the original public claim pointer. It contains no driver capsule,
private owner workspace, raw OCI observations or labels. Replay it with:

```sh
.pixi/envs/default/bin/python \
  examples/utility/verification-guest-archive-v2/replay-public.py.txt
```

The fresh reader denies model imports, process/socket creation, array loading,
new clocks, writes and reads outside the relocated archive. It also denies private
owner recovery and publisher source probing. Original execution and output hashes
agree. The builder resolves temporary paths to avoid macOS's symlinked temporary
ancestors and includes the archive manifest itself in its explicit closure. The
first ad hoc builder stopped on that symlink check before retaining a bundle.
Legacy dispatch replay also remains unchanged.

Current core count is 222. Prepared environment v3 and the full default checkpoint
keep their older source scopes. The guest executor facade, composite-service
integration, initialization recovery, installed/platform/host and runtime/privacy
qualification, independent task admission and margins, and scientific comparison
remain open. Part 5 is incomplete.
