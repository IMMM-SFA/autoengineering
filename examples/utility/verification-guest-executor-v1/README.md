# Candidate guest executor facade

The facade joins original charged composite access, frozen initialization, bounded
input packaging, creation, single-start dispatch and public archive publication.
Its registration pins source/lock, guest/environment, runtime, publisher, policy
and facade implementation. No default scorer/CLI or private runtime is registered.

One public initialization record freezes job, nonce, original claim, owner scope
and absolute deadline before reserved-driver access. Matching partial metadata can
be finished under the suite writer without source/driver access, new clocks, APIs
or science. Unknown files/events, symlinks, conflicting metadata and missing owner
data after a completed marker refuse repair. Another work directory cannot replace
an intended attempt. Reconciliation cannot dispatch or read reserved drivers.

Preparation checks cancellation and deadline before each bounded input read and
before package publication. A completed package cannot renew the deadline for
creation or execution. Filesystem calls remain synchronous and uninterruptible;
checks prevent late daemon launch after they return. This is a qualification limit.
Uncertain creation or missing dispatch evidence remains charged. Early loss before
watchdog arming can leave an unstarted resource requiring explicit cleanup. This
facade does not yet supply every operator cleanup path for that condition.

Original dispatch evidence supports recovery and archive publication without a new
model, attach, START or driver read. A fresh recovery-only constructor loads the
original registration, holds no source/driver/API scope and refuses execution.
Published completion can replay with original work and drivers absent. Pure public
archive readers remain independent of this facade.

The first 8 facade cases passed in 23.06 seconds. The facade/input/legacy-inference
regression passed 64 cases in 136.80 seconds. A later facade/archive run passed 48
and failed one fresh-process harness case in 203.90 seconds. The read barrier had
blocked a lazy public metadata-reader bytecode import. Diagnostic replay identified
the exact import. Reader code is now initialized under model/execution/clock guards
before enabling the strict file-read barrier. All 18 final facade cases passed in
66.12 seconds. Documentation passed 19 cases. Full default tests were not rerun.
Final source snapshots/pins and all test logs are retained here.

All guest peers and results are authored. Actual Unix HTTP/stdio, owned watchdog
processes and fresh reader subprocesses are exercised. No actual container, image
or guest model runs. The metadata fixture includes ordinary authored development
execution. Positive fixtures do not establish Linux, installed-package, private
runtime, physical inference or independent scientific qualification.

The retained public suite contains no driver capsule or private-label canary.

execution. Verification denies model imports, process/socket creation, array
loading, clocks, publisher source probes, writes and reads outside the public
suite. The private work/driver/source/API scopes are absent. Original v2 minimal
public archive replay also remains unchanged.
