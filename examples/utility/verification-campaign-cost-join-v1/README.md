# Campaign cost joins

Suite reports now join public campaign attempt observations to their original
committed campaign state. The reader checks the campaign specification digest,
reserved case/attempt, process receipt hash and nonce, recorded stop state,
lifecycle artifact and output hash. Within a join it reuses campaign projections.
It does not create a campaign controller, import an adapter or launch anything.
Original absolute paths remain metadata after relocation. Ambiguous case markers
are refused. Campaign artifact reads stay within the copied public case directory.

The projection reports outer worker starts and model lifecycle duration. Starts
are subsets of science reservations, not extra scientific or inner solver starts.
The lifecycle timer covers validation, preparation, training, execution and
inspection. It ends before cleanup and overlaps enclosing process time. Do not
sum the two as exclusive work. Failed or legacy/recovered results without a
committed lifecycle artifact retain unknown lifecycle duration. Pending science
permissions do not acquire invented observations or starts.

The disposable campaign cache and mutable scratch metadata are not evidence.
The reader follows the last event-committed controller state and verifies the
committed artifacts. Journal replay rehashes public artifact bytes, including any
committed forcing override. It does not decode model arrays or open original
input/source roots. The training record is validated but its cost has no declared
unit. It is not converted into seconds, CPU/GPU work or dollars, and it does not
qualify an actual training workflow.

The first focused run passed 63 tests in 59.07 seconds. It includes actual owned
authored scalar workers, explicit worker timeout, malformed committed lifecycle,
output, process receipt, state and specification bytes, case mapping, pending
permission and suite report integration. Repeated reads leave journals unchanged.
A test corrupts only the projection cache and scratch metadata and verifies that
the original committed timing remains authoritative. A relocation test removes
the original batch before reading its copy.

The installed wheel matched all 195 current core Python files. A fresh venv
extracted that wheel and reused cached base dependencies without editable
activation or a new dependency solve. A copied authored batch, with input/source
bundles excluded, reconstructed four rows: two outer starts and their committed
lifecycle durations. Four controls denied original checkout access, original test
root access, sockets and subprocesses. PyWake, TOPFARM, OpenMDAO, Anthropic, Torch
and BoTorch were absent. No model inputs or implementation were needed to replay
these receipts. The copied batch, file index, wheel and reader/guard text are
retained. Reader/guard text is for inspection, not automatic archive execution.

Full cost accounting, four independent tasks, actual private scoring, host and
platform qualification and the complete Part 5 experiment remain open. No private
data, provider call or independent scientific comparison ran. Full default/Bayes
suites and frozen scientific matrices were not run for this increment.


The later recovery extension adds campaign-recovery-receipt-v2. After verifying
the original nonce and process-group absence, recovery retains the process
identity/stop, lifecycle artifact and execution seed. It resolves the original
batch reservation without another worker. Malformed process identities remain
unresolved. Legacy receipts without identity remain charged with unknown start
and lifecycle quantities. They are not upgraded from uncommitted scratch files.

An initial interruption fixture raised RuntimeError, which the service correctly
caught, so two intended interruption tests failed. That log is retained under
recovery-tests. The fixture now uses an explicit BaseException to represent
control loss before commit. The corrected recovery group passed 24 tests in
78.73 seconds before the final seed/PGID checks. These are authored interruption
fixtures, not a private-scoring or live-host qualification. Initial source, wheel
and 63/73-test snapshots precede the recovery extension and remain separate.


Final corrected-source regressions passed 200 tests in 315.60 seconds, covering all
campaign tests plus batch science, utility execution, mixed tasks, cost reporting,
CLI and documentation. Final runtime/test hashes were verified afterward. The
corrected wheel matched 195 core files and reconstructed normal/recovered/legacy
archives with 4/2/2 rows under six tested denial controls. Legacy quantities stayed
unknown and charged. Bundled model inputs/source and optional model/provider
packages were absent from these fixture checks. Earlier source/wheel/test evidence
retains its original scope. Full Part 5 remains open.
