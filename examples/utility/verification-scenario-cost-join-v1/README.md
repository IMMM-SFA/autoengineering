# Scenario process cost joins

Suite accounting reads original supervised engineering scenario receipts and
assigns costs to their reserved cells. It verifies the frozen execution binding,
job, process command, completion, stopped identity and bounded stdout before
decoding the saved result. It imports no supplied evaluator or captured source.
Saved metadata retains original absolute command paths. Files are read only from
the current confined batch directory, including after that directory moves.

The projection separates outer process starts, lifecycle duration and declared
count diagnostics. Solver, component and derivative counters stay unknown if the
result does not declare them with count units. Residuals and boolean flags are
excluded. Failed process results retain unknown inner work. Pending reservations
do not gain inferred starts. Diagnostic resource names have their own prefix so
they cannot collide with outer process or lifecycle records.

Outer starts are subsets of generic science reservations. Lifecycle time overlaps
the enclosing process duration. These are separate measures, not extra costs to
add to the enclosing quantities. Complete cost evidence remains false. Training,
resource, provider, preparation and human effort need their own receipts.
