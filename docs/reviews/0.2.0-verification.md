# Version 0.2.0 verification

The integration commit is `6012651`. All eight development branches were renamed to remove
`codex/`, incorporated into `main`, and removed locally. The seven linked worktrees were removed
only after checking their clean state, ancestry, and ignored artifacts. The original draft plan
remains in merged history; the current plan retains its later completion evidence.

## Scope and evidence

All Bayesian optimization backends are experimental. Some examples show benefits, but consistent
advantages across problems, test prediction and total runtime are not established. Passing frozen
gates and adverse results retain their original meaning. The pilot heuristic remains provisional,
and the roadmap retains the TODO to further explore a pilot-based selection rule.

Package, Pixi and Python version declarations agree on 0.2.0. The installed editable package in the
primary checkout reports 0.2.0 and imports from that checkout. Integration commits have verified
SSH signatures. The [independent review](0.2.0-integration-review.md) found a release-provenance
regression, now resolved by exact archived inputs and checks permitting only version-field changes.
The combined results verifier uses that same check. Scientific result manifests and arrays were
not rewritten to claim execution under the new version.

## Local preservation and cleanup

Downloaded open-chain inputs and ignored outputs were copied to the primary checkout and verified
by SHA-256. Other ignored evidence, including older local-model output, is retained with an inventory
under `.git/worktree-backups/20260905`. Disposable environments, bytecode and test caches were
excluded from that backup. Every non-cache ignored file was checked against the backup before
worktree removal.

Only local `main` and the primary checkout remain. The pre-existing stash and untracked
`.claude/settings.json` are unchanged. No remote branches were renamed or deleted, and nothing was
pushed, tagged or published.
